# Rooms Implementation Plan (stage 2 of 5)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ten new rooms are unlocked by stage 1's rewards. The player switches between owned rooms from a new もようがえ screen, and the stage shows the chosen room by day and by night. Every room, today's included, is redrawn as an emptier "からっぽ版" so stage 3 can place furniture.

**Architecture:**
- **Owned rooms are derived, not stored.** `ownedRooms(claimed)` is `home` plus every room whose unlock reward id is in `progress.claimed`. Old saves therefore get their rooms on the first tick, the same way they got their zukan coins.
- **A new reward id for the first send-off.** The flower garden comes from the first generation ending. Stage 1 paid endings without claiming anything, so this plan adds a one-time reward id, `ending:first`. It pays 0 coins and is claimed once `zukan.memories.length ≥ 1`.
- **The current room is the one stored choice.** It lives in a new `home` save section, which stages 3 and 4 will extend with decor and accessories. It is changed with a validated `setRoom` request.
- **Popup.**
  - The empty stage-1 slot becomes the もようがえ button.
  - The button opens a full-screen overlay. The live stage is on top and the room list is below.
  - The stage's background comes from the current room.

**Tech Stack:** Preact, TypeScript, Zod 4, Vitest + @testing-library/preact (happy-dom), Playwright e2e, PixelLab MCP, pngjs art scripts.

**Spec:** `docs/superpowers/specs/2026-11-07-home-shop-and-new-forms-design.md`. This plan covers chapter 3 (stage 2), chapter 6 except 6.3–6.4, 11.1 (the もようがえ button), the へや part of 11.2, the stage-2 parts of 12, 13 (empty rooms and the もようがえ icon) and 14, and appendix D.

**Builds on stage 1** (branch `feat/coins-and-missions`, PR #15). That stage added `progress.claimed`, `settleRewards`, `bookkeepProgress`, `REWARD_IDS`, `MissionList`'s recent rewards, `CoinAmount`, and the null slot in `ActionBar`. This branch is `feat/rooms`, cut from stage 1.

**Deliberately not in this plan:**
- Counting minutes per room, the 「育った部屋」 of spec 6.3. Stage 5 adds it, because that is where evolution reads it. Nothing in stages 2–4 needs it.
- Decor slots and furniture (stage 3).
- The かぐ and きせかえ tabs (stages 3 and 4).
- Refreshing the store screenshots. A bare room makes a poor store image, so they are refreshed in stage 3, once furniture exists.

## Global Constraints

- **Rooms (spec appendix D, verbatim order). The format is id, name ja / en, inside or outside, then how it is unlocked:**

  | id | ja | en | | unlocked by |
  |---|---|---|---|---|
  | home | おうち | Home | in | from the start |
  | garden | はなのにわ | Flower garden | out | `ending:first` (the first generation ending, departed or died) |
  | beach | うみべ | Beach | out | `zukan:10` |
  | forest | もり | Forest | out | `zukan:20` |
  | sweets | おかしやさん | Sweets shop | in | `zukan:30` |
  | snowfield | ゆきのはら | Snowfield | out | `zukan:40` |
  | castle | おしろ | Castle | in | `zukan:50` |
  | washitsu | わしつ | Tatami room | in | `mission:clean:2` |
  | space | うちゅうせん | Spaceship | in | `mission:play:2` |
  | cabin | ログハウス | Log cabin | in | `mission:cook:2` |
  | library | としょしつ | Library | in | `mission:outing:2` |

- **`ending:first`.**
  - It pays 0 coins and is claimed once, when `zukan.memories.length ≥ 1`.
  - Old saves that already have memories get it on their first tick.
  - Like any reward, it goes into `recent` and sets the dot.
- **Switching rooms.**
  - Only owned rooms can be chosen.
  - The engine refuses a locked room (`locked`), a sleeping pet (`asleep`), an egg (`egg`) and a pet that is not alive (`notAlive`). Use the same order as `outingRefusal`, then `locked`.
  - The もようがえ button is disabled while the pet is asleep or an egg, the same as feed, play and outing.
- **Day and night.** These are unchanged. The night picture shows while the pet is asleep, and the room's `<id>_night` replaces `room_night`.
- **Art (spec 13).**
  - Draw 11 rooms, day and night, at 88×68 and opaque.
  - Each is an emptier version of today's picture:
    - keep the walls, floor, windows and the room's identity (the tatami, the porthole, the sweets shelves and so on);
    - remove the free-standing furniture and clutter.
  - Keep these areas plain. They are stage 3's slots, in room pixels (stage px ÷ 4); stage 3 may still adjust them:
    - wall L (6,6,14×14)
    - wall R (68,6,14×14)
    - ceiling (28,0,32×10)
    - floor L (3,39,18×19)
    - floor R (67,39,18×19)
    - rug (32,51,24×12)
  - Outside rooms (garden, beach, forest, snowfield) need only the floor and rug areas kept plain.
  - Use the master palette, checked with `npx tsx scripts/art/check.ts --palette --size 88x68 <files>`.
  - Do not draw a character or face in a room.
  - The もようがえ icon is 16×16 under the same rules as stage 1's icons.
- **PixelLab.**
  - Use the free monthly quota only. Check `get_balance` first.
  - Stop and ask the owner if `generations_remaining` < 100.
  - This plan should use about 80 generations.
- **Popup.** The size stays 360×462. The もようがえ overlay must show the whole 352×272 stage.
- **Save format.**
  - Keep `version: 1`.
  - A save without `home` loads with `{ room: 'home' }`.
  - An unknown or non-string room id becomes `home`.
  - Parsing `home` never fails the save (the same rule as stage 1's ruling P1).
- **Repo rules.**
  - TDD, and watch each test fail first.
  - Coverage stays around where it is.
  - Functions < 50 lines and files < 800 lines.
  - Immutable updates and no `console.log`.
  - UI text goes in both locales.
  - New readouts and buttons get accessible names.
  - Do not run prettier on the repo.
- **Commits.** Conventional format, with **no attribution trailer**. Never push, open a PR or merge without the owner's say-so.
- **Language.** Talk to the owner in Japanese. Code, comments and test names stay in English.

## Review Focus

1. **An old save on its first open, with memories and 23 discoveries.**
   - Expected: on the first tick it owns home, garden, beach and forest, and the もようがえ list shows them unlocked.
   - Expected: `ending:first` is paid once, with 0 coins and one recent line.
   - Tested in Task 1 (`ending:first is claimed once when there is a memory`) and Task 7 (e2e `an old save owns the rooms its rewards unlocked`).
2. **A forged or stale `setRoom`.** The room is locked, unknown or not a string, or the pet is asleep.
   - Expected: the request is rejected (bad shape) or refused (locked or asleep), and the current room is unchanged.
   - Tested in Task 2 (`setRoom requests that are not a known room id are rejected`, and `setRoom refuses a locked room and a sleeping pet`).
3. **A stored room the player no longer owns.** This can happen after a hand edit or a future rename.
   - Expected: the stage falls back to home rather than showing a locked room or a broken background.
   - Tested in Task 4 (`a current room that is not owned shows home`).
4. **Night in every room.**
   - Expected: while the pet is asleep, the current room's night picture shows, for all 11 rooms.
   - Tested in Task 3 (`every room has a day and a night picture`) and Task 4 (`the stage shows the current room by day and by night`).
5. **The room list with only home owned** (a brand-new player).
   - Expected: one selectable room and ten locked ones. Each locked one shows how it is earned, and none can be chosen.
   - Tested in Task 5 (`locked rooms show how to earn them and cannot be chosen`).
