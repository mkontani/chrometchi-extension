# 部屋・お店・着せかえと新しい41体 設計書

- 日付: 2026-11-07
- 対象: `chrometchi-extension` のポップアップとゲームのルール(1.0.1 の上に追加)
- 状態: 下書き(オーナー確認待ち。ビルダーの確認済み)

> 表記ルール: **【オーナー】** はオーナーが会話で決めたこと(提案への「OK」も含む)。**【判断】** は設計者(Claude)が任された範囲で決めたことで、ビルダーが理由を持って変えてよい。数字に付いた【判断】は、遊びながら調整する前提の初期値。

---

## 1. 何を、なぜ作るか

- 2026-11-06 に、PixelLab の枠で次の絵を作った(リポジトリの外、`.superpowers/art-work/2026-11-06/`)。
  - 新しいキャラ41体(こども5・わかもの8・おとな28)。1体16枚(正面・表情5・横向き・歩き8コマ・idle1)。
  - たまごの柄6種、部屋10種(昼・夜)、家具28種、アクセサリー25種。
- 【オーナー】図鑑は、**育て方を変えて何世代も遊ぶうちに、少しずつ埋まっていく**ものにしたい。
- 【オーナー】部屋を切り替えたい。部屋を家具や小物で飾りたい。ペットにアクセサリーを着せたい。
- 【オーナー】**部屋・家具・アクセサリーも、進化の分かれ道に効く**ようにしたい。
- 【オーナー】部屋とお金は、世代のごほうび・図鑑のコンプ率・ミッション達成で少しずつ増える。お金は収穫したものを売っても増える。家具とアクセサリーはお金で買う。

まとめると、「育てる → ごほうびで部屋とコインが増える → 家具やアクセサリーを買う → 部屋や身につけるものを変えて育てる → 新しい子に会う → また増える」という輪を作る。1回に遊ぶのは1〜3分(本体の設計書 1章)なので、どの画面も短く手軽にする。

## 2. ゴール / 非ゴール / アンチゴール

### ゴール
- コインがあり、ごほうび・ミッション・売却で増え、家具とアクセサリーの買い物に使える。
- 部屋を切り替えられ、部屋ごとに家具を飾れる。
- ペットが頭・顔・首にアクセサリーを身につけられる。
- 41体が図鑑に加わり、部屋・家具・アクセサリー・遊び・体重・朝のお世話のどれかで会える。
- 図鑑が系統ごとに並び、まだ会っていない分かれ道がひと目でわかる。

### 非ゴール(今回やらない)
- 部屋をお店で売ること。部屋はごほうびでだけ増える【判断】。
- 買った家具やアクセサリーを売ること、返品【判断】。
- 家具を好きな位置に置くこと(ドラッグ)【オーナー: 決まった置き場所を選んだ】。
- Web ページ上のおさんぽで、アクセサリーや部屋を見せること【オーナー】。
- 新しい通知の種類。今の通知は増やさない【判断】。
- 「あそぶ」のミニゲーム、おでかけ、料理のルールの変更。
- 別のパソコンとのデータの同期。

### アンチゴール(技術的に動いても失敗とみなすもの)
- **新しい子に会う方法が運だけ。** どの子も、遊ぶ人が選べる育て方で会える。レアも「この育て方で、ときどき」にする【オーナー】。
- **コインが無限に増やせる。** いつでも出せるお米やあめ、料理は売れない。売れるのは数に限りがある食材だけ。
- **家具やアクセサリーで、ペットの顔や体がふさがる。** 床の置き場所はペットの左右だけにし、ペットの前には置かない。
- **今のセーブデータが消える・減る。** 前から遊んでいる人の図鑑・レシピ・思い出・食材は、そのまま残る。
- **ポップアップが縦に伸びる。** 高さは今のまま(462px)【オーナー: 1段に5つのボタンを選んだ】。
- 部屋の絵に描いてある家具と、置いた家具が重なって見える。部屋の絵は「からっぽ版」に作り直す(13章)。

## 3. 作る順番

【オーナー】部屋・家具・アクセサリーを先に作り、そのあと41体の進化をつなぐ。【判断】どの段階も、それだけでリリースできる形にする。

| 段階 | 中身 |
|---|---|
| 1 | コイン、ミッション、ごほうび、おみせ(うる)、ボタンの並び替え、ずかんの「ミッション」タブ |
| 2 | 部屋の切り替え(からっぽ版の部屋の絵、部屋のごほうび、もようがえ「へや」) |
| 3 | 家具(おみせ「かぐ」、もようがえ「かぐ」、部屋への表示) |
| 4 | きせかえ(おみせ「アクセサリー」、もようがえ「きせかえ」、82体の位置合わせ) |
| 5 | 新しい41体(進化の条件、名前とヒント、歩き方、図鑑の系統ごとの並び)、たまごの柄 |

- 段階1では「もようがえ」ボタンはまだ出さない。段階2で出す【判断】。
- 段階2の部屋のごほうびは、段階1のごほうびの仕組みに足す。段階1の時点で条件を満たした人には、段階2を入れた最初の起動で、さかのぼって部屋を渡す(5.4)。
- 段階4の位置合わせは、その時点にいる42体分を作り、段階5で41体分を足す。

## 4. 全体の流れ

```
育てる ──世代の終わり・図鑑の数・ミッション──▶ コイン・部屋
  ▲                                              │
  │                                   おみせで家具・アクセサリーを買う
  │                                              ▼
新しい子に会う ◀── 部屋・家具・身につけるもの・遊び・体重・朝のお世話で分かれ道が変わる
```

## 5. コイン・ミッション・ごほうび

### 5.1 コイン
- 単位は「コイン」(英語 coins)【判断】。右上の体重の下に、コインの絵と数字を出す【オーナー】。
- コイン・部屋・買ったもの・ミッションの進み具合は、食材の棚や畑と同じく**次の世代に引き継ぐ**【オーナー】。「さいしょから」(restart)でも消えない【判断】。
- 上限は 99999 コイン【判断】。超える分は捨てる。

### 5.2 ごほうびの一覧

| きっかけ | コイン | 部屋 |
|---|---|---|
| 世代の終わり(元気に旅立った) | 100 | 1回目の世代の終わりで「花の庭」(旅立ちでも、亡くなったときでも) |
| 世代の終わり(亡くなった) | 30 | 同上 |
| 図鑑で 10・20・30・40・50 体見つけた | 50 ずつ | 海辺・森・お菓子屋・雪原・お城 の順に1つずつ |
| 図鑑で 60・70・80 体見つけた | 100 ずつ | なし |
| ミッションの各段階 | 付録 E | 付録 E(4部屋) |

- 数字はすべて【判断】。部屋の順番は【判断】で、新しいこどもに会える5部屋(花の庭・海辺・森・お菓子屋・雪原)を先にした【オーナー: OK】。
- 図鑑の数は、`zukan.discovered` の数(たまご・あかちゃんも数える)。
- **目標の目安【判断】:** 家具とアクセサリーを全部そろえるのに、ふつうに遊んで 20〜30 世代。ビルダーは、売値(5.5)と値段(付録 B・C)を、この目安に合うように調整してよい。目安を確かめるテスト(15章)を置く。

### 5.3 ミッション
- 回数の目標を3段階ずつ、6種類【オーナー: OK】。回数は、世代をまたいで数え続ける。
- 数える行動【判断】(どれも結果が `ok` のときだけ数える。断られたら数えない):

| ミッション | 数えるもの |
|---|---|
| そうじ | `clean` |
| あそぶ | `play`(勝ち負けは問わない) |
| ごはん | `feed`(料理・食材・お米・あめ どれでも) |
| おでかけ | `forage`(釣り・狩り・採集) |
| しゅうかく | 畑の `harvest` |
| りょうり | `cook`(なぞの料理も数える) |

- 段階・ごほうびは付録 E。1つの段階を達成すると、次の段階の目標が出る。最後の段階の後は「ぜんぶ達成」と出す。
- ごほうびは、達成した瞬間に自動でもらえる【判断・オーナーOK】。

### 5.4 ごほうびのお知らせ
- ごほうびをもらったら、ずかんのボタンに小さな印を付ける。ずかんの「ミッション」タブを開いたら消す【判断・オーナーOK】。
- 「ミッション」タブには、最近もらったごほうびを新しい順に最大5件出す(例:「森をもらった」「50コインもらった」)【判断】。
- 前から遊んでいる人へ: 新しい版を最初に起動したとき、すでに条件を満たしているごほうび(図鑑の数、1回目の世代の終わり)を、まとめて渡す。ミッションの回数は0から数える(今までの回数は残っていないため)。

### 5.5 おみせ「うる」
- 売れるのは食材8種だけ(魚・エビ・肉・たまご・木の実・きのこ・野菜・果物)【オーナー: 収穫したもの / 判断: おでかけの食材も含める】。
- お米・あめ(いつでも出せる)と、料理は売れない。
- 売値は1つ 1〜3 コイン【判断】(例: 木の実・きのこ・たまご 1、魚・野菜・果物 2、肉・エビ 3)。おでかけは1日に各3回までなので、5〜10 コインだと 5.2 の目安より4〜5倍早くそろってしまう。
- 「1つうる」と「ぜんぶうる」のボタン。確かめのダイアログは出さない【判断】(取り返しがつかないが、値段が小さい)。
- ペットが寝ていても、たまごでも、売れる【判断】。

## 6. 部屋

### 6.1 部屋の一覧
- 今の部屋(`home`、ピンクの部屋)に、10部屋を足して11部屋【オーナー】。一覧は付録 D。
- 最初から持っているのは `home` だけ。ほかはごほうびで増える(5.2)。
- 昼と夜は、今と同じく自動で切り替わる(寝ているあいだは夜の絵)【判断・オーナーOK】。

### 6.2 部屋を切り替える
- もようがえ「へや」タブで、持っている部屋から選ぶ。持っていない部屋はかげで出し、もらい方を小さく書く(例:「図鑑で20体」)【判断】。
- 切り替えはいつでもできる。ペットが寝ているあいだ・たまごのあいだは、もようがえ自体が使えない(11.2)。

### 6.3 育った部屋
- ペットが起きているあいだ、1分ごとに「今いる部屋」の分数を数える。段階が変わるたび(進化のたび)に0に戻す。食べ物の回数(`foodCounts`)と同じ扱い。
- **育った部屋** = その段階で、いちばん長く過ごした部屋。いちばんが2つ以上あるとき、または1分も数えていないときは、今いる部屋【判断】。
- たまごの時期は数えない(ペットはたまごのあいだ、もようがえを使えない)。

### 6.4 部屋が効く分かれ道
- 赤ちゃん → こどもで、育った部屋が5部屋のどれかなら、その部屋のこどもになる(9.2)【オーナー: OK】。

## 7. 家具

### 7.1 置き場所
- 【オーナー】決まった置き場所に置く。部屋ごとに最大6か所。

| 置き場所 | 数 | 置けるもの(例) |
|---|---|---|
| 壁 | 2(左・右) | 時計、絵 |
| 天井 | 1 | ガーランド、ちょうちん |
| しき物 | 1(ペットの足もと) | ラグ、クッション |
| 床 | 2(ペットの左・右) | 植物、いす、水そう など |

- 家具ごとに、置ける置き場所の種類が1つ決まっている(付録 B)。
- 森・海辺・花の庭・雪原の外の部屋には、壁と天井がない。床2としき物だけ【判断・オーナーOK】。
- 置き場所の位置(ステージ上の四角)は、部屋の絵に合わせて部屋ごとに決める(付録 D の初期値をビルダーが絵を見て直す)。床の置き場所は、ペット(ステージの x 112〜240)にかからない。
- 1か所に1つ。埋まっている場所に置くと入れ替わる【判断・オーナーOK】。
- 「はずす」で空にできる。
- 持っている家具は、どの部屋にも置ける。同じ部屋には1つだけ【判断】(1つの部屋の中で同じ植物を2か所には置けない)。
- 飾りつけは部屋ごとに覚える。部屋を切り替えると、その部屋の飾りつけに戻る【判断・オーナーOK】。

### 7.2 見え方
- 家具は絵の2倍の大きさ(32px の絵なら 64px)で、今のごはんの絵と同じ【判断・オーナーOK】。24px の絵は 48px。
- 置き場所の四角の中で、下そろえ・左右中央に置く。
- 重なりの順番(奥から): 部屋の絵 → 壁・天井 → しき物 → ペット → 床。床の家具はペットにかからないので、ペットより手前でもよい。
- 夜の絵のときは、家具も暗くする(ステージの暗さの重ねと同じ)【判断】。

### 7.3 家具の種類と分かれ道
- 家具を8つの種類に分ける。種類のない家具(おもちゃなど)もある(付録 B)【オーナー: OK】。

| 種類 | 系統 | 例 |
|---|---|---|
| あかり | ほのお(solar) | ろうそく、ランプ |
| みず | みず(water) | 水そう、花びん |
| くさき | つち(earth) | 植物、サボテン、盆栽 |
| そら | かぜ(wind) | ガーランド、望遠鏡 |
| からくり | きかい(metal) | 時計、オルゴール、トイピアノ |
| よる | よる(lunar) | ちょうちん、ペットベッド |
| きらきら | ほし(ether) | トロフィー、地球儀、ツリー |
| くつろぎ | どっしり(heavy) | ひじかけいす、クッション、テーブル、スツール、ラグ |

- こども → わかもので、**育った部屋に置いてある家具の種類**を数え、いちばん多い種類が1つに決まれば、その系統の新しいわかものになる(9.3)。数えるのは進化の瞬間に置いてある家具【判断】。

## 8. きせかえ

### 8.1 身につける場所
- 【オーナー】頭・顔・首に1つずつ、最大3つ。
- アクセサリーごとに場所が1つ決まっている(付録 C)。頭17・顔3・首5。
- 持っているアクセサリーは何回でもつけ外しできる。
- 進化しても外れない。新しい姿でもそのまま【判断・オーナーOK】。
- 世代が変わっても、持ち物は残る。**身につけているものは、新しいたまごで外れる**【判断】(たまごは身につけられないため)。
- たまごのあいだは身につけられない。

### 8.2 見え方
- ペットと同じ点の大きさ(絵の4倍)で重ねる【判断・オーナーOK】。16px の絵なら 64px。
- キャラごとに頭・顔・首の「つける点」を決める(32px の絵の座標)。アクセサリー側にも「合わせる点」を決める(頭: 下の中央、顔: 中央、首: 上の中央)。2つの点をそろえて重ねる【判断】。
- 1体の中では、どの表情でも同じ点を使う【オーナー: OK】。ぴょこぴょこ動く(idle0/idle1、`pet--bounce`)ときは、アクセサリーも一緒に動く。
- 重なりの順番: ペット → 首 → 顔 → 頭。
- ポップアップの中だけで見せる。おさんぽ中は見せない【オーナー: OK】。図鑑の絵にも出さない【判断】。

### 8.3 つける点の作り方
- 【判断】ビルダーは、絵から目安を自動で出すスクリプトを作る(頭 = いちばん上の点の少し下、顔 = 目の高さ、首 = 顔の下)。それを 82体 + あかちゃん の表(`src/data/anchors.ts` など)にし、一覧の画像(全員に帽子・めがね・蝶ネクタイを重ねたもの)を作って、目で見て直す。
- この一覧の画像は、オーナーの確認に回す(段階4・5の最後)。

### 8.4 アクセサリーが効く分かれ道
- わかもの → おとなで、進化の瞬間に決まったアクセサリーを身につけていると、その系統のレアに、ときどき会える(9.4)【オーナー: OK】。

## 9. 新しい41体と進化

### 9.1 段階ごとに効くもの【オーナー: OK】

| 段階 | 効くもの | 新しい子 |
|---|---|---|
| 赤ちゃん → こども | 育った部屋 | 5体 |
| こども → わかもの | 育った部屋の家具の種類 | 8体(8系統に1体ずつ) |
| わかもの → おとな | 遊び(ストップ)・体重(軽い)・朝のお世話、レアはアクセサリー | 28体(8系統に3体ずつ + レア4体) |

- 今の分かれ道(お世話のミス・体重・ミスなし・食べ物・遊び)は残す。お世話のミスや体重で決まる道(ケム・ダンゴ・カゲ・ポヨ)は、今までどおり新しい道より優先【オーナー: OK】。
- どれにも当てはまらなければ、今までどおりふつうの子(モチ・ギア・各系統のふつうのおとな)【オーナー: OK】。

### 9.2 こども(赤ちゃんから)
- 新しい条件 `room: RoomId`(育った部屋がその部屋)。
- 優先度【判断】: ケム 90 → ダンゴ 80 → **部屋のこども 75** → ホシ 70 → モチ 0。

| 部屋 | こども |
|---|---|
| 花の庭 | ピコ(ヒヨコ) |
| 海辺 | アワ(シャボン玉) |
| 森 | タネ(どんぐり) |
| お菓子屋 | アメ(キャンディ) |
| 雪原 | ユキ(雪玉) |

### 9.3 わかもの(こどもから)
- 新しい条件 `decorKind: DecorKind`(7.3 の数え方で、いちばん多い種類がそれ)。
- 優先度【判断】: キラリ 100 → カゲ 90 → ポヨ 80 → **家具のわかもの 60** → 食べ物のわかもの 50 → ギア 0。
- 家具のわかものは、9体すべてのこどもからなれる。
- 新しいこども5体は、今のカゲ・ポヨ・食べ物のわかもの4体・ギアの `from` にも入る(キラリはホシからだけのまま)【判断】。どのこどもにも、ふつうの道(ギア)が必ずある。
- 新しいわかものは系統に入り、おとなになるときは、その系統のおとなたちに進む(各系統のおとなの `from` に足す)。

| そら | ポツリ(雨雲) | かぜ |
| からくり | ピリリ(かみなり) | きかい |
| よる | ソロリ(おばけ) | よる |
| きらきら | ツララ(つらら) | ほし |
| くつろぎ | コロン(小石) | どっしり |

### 9.4 おとな(わかものから)
- 各系統に3体を足す【オーナー: OK】。ストップと軽いは今の条件で書ける(`dominantGame: 'stop'`、`weight: 'light'`)。朝は新しい条件(下)。
- 新しい条件 `wearing: AccessoryId`(進化の瞬間に身につけている)。レア4体に使う。
